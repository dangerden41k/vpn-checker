# DangerVPN 🚀

Автоматическая VPN-подписка: серверы проверяются сами каждые **3 часа**, в подписке остаются только рабочие — мёртвые отсеиваются, новые подхватываются сами. Имена вида «🇳🇱 Нидерланды — Амстердам» (флаг + страна — город по гео IP).

## 📲 Подписка

Добавь ссылку в клиент (Happ, v2rayN, NekoBox, Hiddify, Streisand и т.п.):

| Что | Ссылка |
| --- | --- |
| **Основная — все серверы** | https://raw.githubusercontent.com/dangerden41k/vpn-checker/main/sub |
| 🤍 Только «Белый» — для блокировок и белых списков | https://raw.githubusercontent.com/dangerden41k/vpn-checker/main/white_base64.txt |
| 🖤 Только «ЧС» — обычный интернет | https://raw.githubusercontent.com/dangerden41k/vpn-checker/main/black_base64.txt |

- Основная подписка задана в Happ-формате: клиент сам обновляет её каждые 3 часа (`#profile-update-interval: 3`), ничего настраивать не нужно.
- Текстовые версии тех же списков: `sub_plain.txt`, `white_plain.txt`, `black_plain.txt`.
- **Подписка не обновляется, тайм-аут?** Под блокировками GitHub бывает недоступен напрямую. Обнови подписку, пока подключён к любому рабочему VPN (или включи в клиенте «обновлять через прокси»), дальше всё будет тянуться само.

## 🤍 Белый и 🖤 ЧС — что это

| Категория | Когда использовать | Что это технически |
| --- | --- | --- |
| 🤍 **«Белый»** | Когда интернет **заблокирован** (режим «белых списков», региональные блокировки) | Сервер живёт за доменом (CDN, workers.dev, ddns) и/или работает по UDP с обфускацией (`hysteria2`, `tuic`) — DPI до такого добраться сложнее |
| 🖤 **«ЧС»** | Когда интернет **не заблокирован** — обычный Wi-Fi или LTE | Обычные TCP-серверы на голых IP. Работают как часы, пока трафик к «серым» IP не зарежут |

## ⚙️ Как делаются серверы

1. **Сбор ссылок.** Парсим публичные VPN-агрегаторы: тысячи ссылок vless / vmess / trojan / ss / hysteria2. Откуда именно — не раскрываем: список источников не хранится в репозитории.
2. **Дедуп.** Повторы убираем по связке «хост + порт + учётка», чтобы один сервер не попадался десять раз.
3. **Быстрый этап.** TCP-подключение к каждому серверу: мёртвые поры отсеиваются сразу.
4. **Глубокий этап.** Через каждого выжившего поднимаем настоящий туннель (Xray-core / sing-box) и качаем по нему реальную страницу. «Живым» сервер считается только если трафик действительно прошёл.
5. **Имена и сортировка.** По IP определяем страну и город (гео-база ipwho.is) — получаются понятные имена «🇩🇪 Германия — Франкфурт»; список сортируется по странам.
6. **Публикация.** Готовые подписки коммитятся в этот репозиторий, клиент забирает их по ссылке. Через 3 часа всё повторяется.
